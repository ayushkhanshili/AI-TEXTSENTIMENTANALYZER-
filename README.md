
# 🤖 AI Text Sentiment Analyzer

## About the Project

AI Text Sentiment Analyzer is a machine learning
based web application that analyzes text and
identifies its emotional sentiment.

It classifies text into three categories:

- Positive
- Negative
- Neutral

## Technologies Used

- Python
- Artificial Intelligence
- Natural Language Processing (NLP)
- Transformer Models
- XLM-RoBERTa
- Streamlit
- PyTorch

## Features

- Multilingual sentiment analysis
- Hindi and English support
- Positive, Negative and Neutral classification
- Confidence score
- Sentiment probability chart
- Downloadable analysis report
- Interactive web interface

## AI Model

cardiffnlp/twitter-xlm-roberta-base-sentiment

## How to Run

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Developed For

Class 12 Artificial Intelligence Project.

## Disclaimer

AI predictions are not always correct.
Results may vary depending on language,
context, sarcasm and text quality.
